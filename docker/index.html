Entorno de trabajo

Los ejemplos de clase se ejecutan en un contenedor php-apache (puerto 8080) con MySQL (host db, puerto 3306 publicado para conectar con DataGrip). Descarga el entorno, descomprímelo y arráncalo:

⬇ entorno-dwes-docker.zip

cd entorno-dwes
docker compose up -d --build
# Web:       http://localhost:8080
# DataGrip:  host localhost · puerto 3306 · usuario dwes · base tienda

docker-compose.yml

services:
  web:
    build: ./docker/php
    ports: ["8080:80"]
    environment:
      DB_HOST: db
      DB_NAME: tienda
      DB_USER: dwes
      DB_PASS: dwes_dev
    volumes:
      - ./src:/var/www/html
    depends_on: [db]
  db:
    image: mysql:8.4
    environment:
      MYSQL_ROOT_PASSWORD: root_dev
      MYSQL_DATABASE: tienda
      MYSQL_USER: dwes
      MYSQL_PASSWORD: dwes_dev
    ports: ["3306:3306"]            # DataGrip se conecta a localhost:3306
    volumes:
      - db_data:/var/lib/mysql
      - ./db/init:/docker-entrypoint-initdb.d
volumes:
  db_data:

Léeme

Entorno de DWES (Docker + DataGrip)
1) docker compose up -d
2) Navegador: http://localhost:8080  (las paginas PHP se guardan en ./src)
3) DataGrip: New > Data Source > MySQL: host localhost, puerto 3306, usuario dwes, contrasena dwes_dev, base tienda
4) Desde PHP (dentro del contenedor) el servidor de base de datos es 'db', no 'localhost'.
Las contrasenas son solo para el entorno de clase.
