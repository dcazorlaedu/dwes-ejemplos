Una secuencia progresiva, de lo básico a proyectos integrados. Cada unidad trabaja todos sus RA y todos sus criterios de evaluación.

Ver ejercicios Preparar el entorno (Docker + DataGrip)

Cómo usar la batería. Los ejercicios van por unidad y, dentro de cada una, por dificultad creciente. Las PHP se ejecutan siempre desde el navegador (http://localhost:8080) con el entorno Docker del material y la base de datos se consulta también desde DataGrip. No hay soluciones públicas: cada ejercicio incluye criterios de aceptación observables para que compruebes tu trabajo.
