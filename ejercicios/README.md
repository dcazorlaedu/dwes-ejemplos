# Batería de ejercicios de DWES

20 ejercicios en carpetas individuales (`NN_ejercicio_UTN`), ordenados por UT y dificultad. Cada UT trabaja **todos** los RA de la unidad (la UT2 trabaja RA2 y RA3; la UT7, RA8 y RA9) y cubre todos sus criterios de evaluación. Los ejercicios son públicos y **no incluyen soluciones**: cada uno trae criterios de aceptación observables para que el alumnado compruebe su trabajo.

Origen editable: `ejercicios.json`. Para regenerar el índice, las páginas web y los README:

```sh
python3 ejercicios/build.py
```

Entorno de prácticas (Docker + DataGrip): [`material/LEEME.md`](material/LEEME.md). Todos los datos son ficticios; ejecuta el material solo en bases de datos de pruebas.
